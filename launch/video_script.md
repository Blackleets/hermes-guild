# Guion vídeo demo GUILD — <90 segundos

Formato: captura de pantalla (terminal + chats) con voz o texto grande.
Sin prometer nada que la demo real no haga: todo lo que se ve sale de
`scripts/demo_e2e.py` ejecutándose de verdad.

**Enfoque (06/11): Hermes primero.** El vídeo habla a los builders de
Hermes — es la casa, el cliente flagship y la ola 1. Muse aparece
como el puente (ola 2) dentro de la historia, y el resto de agentes
solo como apertura final (ola 3, API abierta).
